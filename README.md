# Amazon Private Triage Agent

An autonomous multi-agent triage workflow built using Relevance AI. This private repository contains the system documentation, workflow architecture proofs-of-work, and operational logic designed to streamline internal customer request processing and classification.

## Architecture Overview
- **Platform:** Relevance AI (Low-Code / No-Code Autonomous Agent Engine)
- **Core Function:** Automated intake, intent classification, and structured data routing for private triage operations.
